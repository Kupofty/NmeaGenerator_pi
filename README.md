# NmeaGenerator_pi

NmeaGenerator is an [OpenCPN](https://opencpn.org) plugin for generating, transmitting, and simulating **NMEA 0183** data without physical navigation hardware.



### Features
The plugin provides tools to:

* Send custom NMEA sentences
* Build common NMEA sentences
* Generate configurable NMEA data streams
* Simulate own-ship navigation
* Simulate AIS targets in real time

Useful for OpenCPN development, testing, AIS/GPS simulation, and NMEA debugging.



## Documentation

Available in the online [User Manual](https://kupofty.github.io/NmeaGenerator_pi/nmeagenerator_plugin/index.html).



## Installation

Install directly through plugin catalogue (**OpenCPN → Options → Plugins**), or download packages from [Cloudsmith](https://cloudsmith.io/~kupoftyopencpn/repos/).

To build from source, see [`INSTALL.md`](INSTALL.md).
